# 安全反馈 / Security

## 中文

如果你发现安全问题，请不要在公开 Issue 中发布密码、验证码、恢复代码、个人文件内容或其他敏感信息。

请优先使用 GitHub 的私密安全报告页面：

<https://github.com/b0vibe/mac-clean-helper-releases/security/advisories/new>

如果该页面暂时不可用，请只创建一个不包含敏感细节的 [公开 Issue](https://github.com/b0vibe/mac-clean-helper-releases/issues)，说明需要私密联系。不要在公开页面补充漏洞细节。

收到报告后，我们会先确认问题和受影响版本，再通过私密渠道回复处理进度。公开测试版不承诺固定响应时限。

## English

If you discover a security issue, do not post passwords, verification codes, recovery codes, personal file contents, or other sensitive information in a public Issue.

Use GitHub's private vulnerability reporting page whenever possible:

<https://github.com/b0vibe/mac-clean-helper-releases/security/advisories/new>

If that page is temporarily unavailable, create a [public Issue](https://github.com/b0vibe/mac-clean-helper-releases/issues) containing no sensitive details and ask for private contact. Do not add vulnerability details publicly.

After receiving a report, we will confirm the issue and affected versions before responding through a private channel. The public beta does not promise a fixed response time.
